# NuGet packaging and CI implementation plan

> **For agentic workers:** Use superpowers:executing-plans and verification-before-completion.

**Goal:** Prepare LunchMoney.Sdk 0.1.0 with MIT metadata, repeatable builds,
Windows/Linux CI and one README that works on GitHub and NuGet.org.

**Architecture:** Keep the existing net11.0 SDK and generated client unchanged.
Use SDK-style NuGet packing, the SDK's built-in Source Link support, locked
dependencies and GitHub Actions artifacts. Publishing to NuGet is a separate step.

**Tech stack:** .NET SDK 11.0.100; Kiota CLI 1.38.0; GitHub Actions.

**Spec:** User request and metadata answers: MIT; public repository
https://github.com/brunofelixns/LunchMoney.Sdk.

## Constraints and review focus

- Preserve the 71 tests, both injection paths and all Generated files.
- Include accurate metadata, README, license, XML documentation and symbols.
- Use only absolute image/documentation URLs in the packaged README; the banner
  must be hosted on the repository's main branch before public package release.
- Lock restore and verify build/test/pack on Windows and Linux in CI.
- Do not publish a NuGet package or store publishing credentials in the repository.
- No local Git checkout exists. Prepare files in place; Git initialization or
  upload is separate from file preparation. Use generated-file hashes as baseline.
