# Documentation

**English** · [Español](es/README.md) · [Project home](../README.md)

Start with installation and configuration, then choose the injection style that
matches your application's lifetime. Both use the same registration.

| Guide | What you will find |
| :--- | :--- |
| [Getting started](en/getting-started.md) | Package installation, CI artifacts and local feeds. |
| [Configuration](en/configuration.md) | API token, user secrets, environment variables and validation. |
| [Dependency injection](en/dependency-injection.md) | Direct typed injection, the SDK factory and complete ASP.NET Core examples. |
| [Background services](en/background-services.md) | A complete worker with recovery, backoff and graceful shutdown. |
| [Error handling](en/error-handling.md) | HTTP errors, retries, timeouts and cancellation. |
| [Development](en/development.md) | Kiota regeneration, build/test, CI, packing and release publishing. |
| [Architecture](en/architecture.md) | HTTP lifetimes, the background-service factory and the generated-code boundary. |

Every guide has a matching Spanish version and a language link at the top.
English is the primary documentation language. Keep both versions and their
executable examples in sync when making changes.
